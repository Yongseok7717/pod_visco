# pod_visco

Proper Orthogonal Decomposition (POD) reduced-order models (ROM) for the
viscoelastic wave equation, discretized in space with a symmetric interior
penalty discontinuous Galerkin (SIPDG) method and in time with a
theta-scheme (Euler / Crank–Nicolson). The internal (memory) variables of
the standard linear solid model are updated algebraically at each time
step, following the Zener/Prony-series relaxation model
`varphi(t) = varphi0 + sum_q varphi_q * exp(-t/tau_q)`.

The repository contains two numerical experiments built with
[FEniCSx](https://fenicsproject.org/) (`dolfinx`).

## Problem 1 — Manufactured-solution convergence study

`Problem_1/ex1.py`

Verifies the DG–POD ROM against a manufactured (exact) solution on the
unit square, using POD bases built from **inexact snapshots** generated by
a coarse full-order model (FOM) time march (rather than direct
interpolation of the exact solution).

- `dg_spatial_convergence()` — fixes the time step and refines the mesh
  (`Nxy = 4, 8, 16, 32`) and polynomial degree (`k = 1, 2`) to measure
  spatial convergence rates of the FOM and of the ROM built with POD
  inner products `W ∈ {I, M, A}` (Euclidean, mass-weighted,
  energy/stiffness-weighted).
- `dg_temporal_convergence()` — fixes the mesh and refines the time step
  (`Nt = 200, 400, 800, 1600`) under Euler and Crank–Nicolson schemes to
  measure temporal convergence rates.
- Errors are reported in the max-in-time discrete L2 norm
  (`sqrt(eᵀ M e)`) and broken H1 norm (`sqrt(eᵀ (M+G) e)`).
- Results are written to `results_spatial/dg_spatial_convergence.csv` and
  `results_temporal/dg_temporal_convergence.csv`; `plot_space.py` and
  `plot_time.py` turn these into the convergence plots under
  `dg_spatial_plots/` and `dg_temporal_plots/`.

## Problem 2 — Long-time ROM performance on a loaded viscoelastic block

`Problem_2/ex2.py`

Simulates a PDMS-like viscoelastic block (plane-strain, Zener model with
two relaxation times) on the unit square under a traction load, comparing
a fine reference FOM against POD-ROMs built from coarse-FOM snapshots for
several POD dimensions (`ell ∈ {10, 20, 50, 100, 200}`).

- Records the displacement history at a probe point inside the domain
  (`x_p = (0.203, 0.497)`) for the reference FOM and each ROM, over both
  a short and a long time horizon.
- Reports ROM accuracy vs. `ell`, timing (setup/solve/snapshot), and the
  discarded POD singular-value tail.
- Intermediate FOM snapshots, the reference probe history, and each ROM's
  results are checkpointed as `.npz` files in `results_longtime/` so the
  expensive offline stages don't need to be recomputed when only
  post-processing changes.
- `plot_probe.py` regenerates the probe displacement history plots
  (`results_longtime/probe_displacement_histories.png`,
  `figures/probe_displacement_histories_{short,long}.pdf`) from the saved
  data.

## Environment

Both scripts were developed against:

```bash
conda create -n visco-rom python=3.11
conda activate visco-rom
conda install -c conda-forge fenics-dolfinx basix petsc4py mpi4py numpy scipy matplotlib pandas
```

## Running

```bash
cd Problem_1 && python ex1.py       # spatial + temporal convergence study
cd Problem_2 && python ex2.py       # long-time ROM accuracy/performance study
```

Each script writes its numerical results (CSV/NPZ) and figures into the
`results_*`/`figures` subfolders shown above.
